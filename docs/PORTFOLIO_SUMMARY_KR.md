# DEFENSE SEMI B2B MARKET — 포트폴리오 요약

## 프로젝트 소개
반도체 공정·기술 지식에서 제품, 공급사, RFQ까지 이어지는 **B2B Manufacturing Intelligence + Sourcing Platform**을 기획·설계·구현했습니다.

## 문제 정의
반도체 B2B 구매는 제품 이름만 검색해서 끝나지 않습니다. 적용 공정, 장비, 소재, 공급사, 기술 정보와 문의가 서로 연결돼야 합니다. 이를 위해 일반 쇼핑몰이 아닌 **Knowledge → Process → Product → Supplier → RFQ** 구조를 설계했습니다.

## 담당 범위
- 서비스 기획 / IA
- UX/UI / Responsive Design
- 데이터 모델링
- Product / Supplier / Knowledge 관계 설계
- Next.js / TypeScript 구현
- PostgreSQL + Prisma 연동
- RFQ DB 저장
- Admin CMS CRUD
- Published workflow
- DB QA / Responsive QA
- AI 이미지 자산 제작 및 적용

## 핵심 기능
- 제품/공급사/기술 콘텐츠 검색 및 필터
- 제품 ↔ 공급사 연결
- Knowledge ↔ Product 연결
- 3-step RFQ
- Admin Product / Supplier / Knowledge 관리
- PostgreSQL Published data sync
- RFQ / Item / Supplier Match 실제 DB 저장
- My Desk
- 반응형 UI

## 기술 스택
`Next.js · React · TypeScript · PostgreSQL · Prisma · Zod`

## 한 줄 성과
**반도체 도메인 지식을 정보구조·데이터 모델·B2B UX로 변환하고, 실제 DB와 Admin까지 연결되는 포트폴리오 MVP를 완성했습니다.**
