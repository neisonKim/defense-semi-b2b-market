# Portfolio / LinkedIn Copy

## 1. 포트폴리오 제목
**DEFENSE SEMI B2B MARKET — Semiconductor Manufacturing Intelligence + Sourcing Platform**

## 2. 2줄 소개
반도체 기술 지식에서 공정·제품·공급사 탐색과 RFQ까지 이어지는 B2B 소싱 플랫폼입니다.  
서비스 기획과 UX/UI부터 Next.js, PostgreSQL, Prisma, Admin CMS까지 하나의 구조로 구현했습니다.

## 3. 이력서용 3줄
- 반도체 B2B 소싱 플랫폼 IA·UX/UI 및 Product/Supplier/Knowledge 데이터 구조 설계
- Next.js + PostgreSQL + Prisma 기반 공개 카탈로그, Admin CRUD, RFQ 저장 기능 구현
- Desktop/Tablet/Mobile 반응형 QA 및 기술 콘텐츠-제품-공급사 연결 UX 구축

## 4. LinkedIn 짧은 버전
반도체 산업의 기술 정보와 실제 B2B 소싱 흐름을 하나로 연결하는 개인 프로젝트를 진행했습니다. Knowledge → Process → Product → Supplier → RFQ 구조를 설계하고, Next.js·PostgreSQL·Prisma 기반으로 Admin CMS와 실제 RFQ DB 저장까지 구현했습니다. 단순한 UI 시안이 아니라 도메인 지식, 정보구조, 데이터 모델, 전환 UX를 실제 코드베이스로 연결하는 데 초점을 맞췄습니다.
